# Capslate

macOS 菜单栏截图翻译工具：按一下快捷键，框选屏幕上任意区域，马上得到译文。

文字识别用系统自带的 Vision（离线、免费），翻译可以同时调用多个翻译源对照着看。原生 Swift 编写，没有 Electron。

## 功能

- **截图翻译**（⌘W）：框选屏幕区域 → 识别文字 → 翻译，一步完成
- **静默截图识字**（⌥W）：框选后只把识别出的文字写进剪贴板，不弹窗，菜单栏图标闪一下表示成功
- **截图识字（弹窗）**：识别后在窗口里显示原文，同时复制到剪贴板
- **粘贴图片识别翻译**：识别剪贴板里的图片并翻译
- **划词翻译**（⌘E）：选中任意 app 里的文字直接翻译
- **输入翻译**（⌥A）：打开窗口手动输入
- **剪贴板监听**：开启后复制文字即自动翻译
- **多个翻译源同时出结果**：OpenAI 兼容接口（默认 DeepSeek，提示词可自定义）、谷歌翻译（免费，无需 key）、DeepL（可申请免费 key）
- 英文译文可一键复制为驼峰（`helloWorld`）或蛇形（`hello_world`），方便起变量名
- OCR 断行合并：把截图里被拆成多行的同一段文字合回去再翻译
- 翻译记录、自定义快捷键、主题、字号、窗口位置（跟随鼠标或上次位置）、开机自动启动

快捷键都可以在设置里修改；「截图识字（弹窗）」和「粘贴图片识别翻译」默认没有快捷键，需要的话自己设。

## 系统要求

- macOS 26 及以上（界面使用 Liquid Glass）
- Apple Silicon
- Xcode 或 Xcode 命令行工具（`xcode-select --install`）

## 下载安装

1. 到 [Releases](https://github.com/cracya01/capslate/releases) 下载最新的 `Capslate-*.dmg`，双击打开
2. 把 `Translator.app` 拖进 `Applications` 文件夹
3. **首次打开需要手动放行**：app 没有经过苹果公证，直接双击会提示「无法验证开发者」。任选一种方法：
   - 双击打开一次后，到「系统设置 → 隐私与安全性」，在页面下方点「仍要打开」
   - 或在终端执行：
     ```bash
     xattr -dr com.apple.quarantine /Applications/Translator.app
     ```

## 从源码编译安装

```bash
./build.sh
```

脚本会在临时目录编译，装到 `/Applications/Translator.app` 并启动。app 只在菜单栏显示图标，不出现在 Dock。

签名：如果钥匙串里有名为 `Local Self-Signed Code Signing` 的代码签名证书就用它，否则使用临时签名（ad-hoc）。用固定证书的好处是重新编译后，系统授予的权限不会丢；用临时签名的话，每次重新编译后可能要重新授权。

## 权限

第一次使用相应功能时系统会提示授权：

| 功能 | 需要的权限（系统设置 → 隐私与安全性） |
|---|---|
| 截图翻译、截图识字 | 屏幕录制 |
| 划词翻译 | 辅助功能 |

授权后需要退出并重新打开 app。

## 翻译源配置

第一次启动如果没有可用的翻译源，会自动打开设置里的「翻译源」页。谷歌翻译开箱即用；DeepSeek / OpenAI 兼容接口和 DeepL 需要填自己的 API key。key 只保存在本机。

## 代码结构

| 文件 | 内容 |
|---|---|
| `Translator.swift` | 程序入口、菜单栏、快捷键与各功能的串联 |
| `Engines.swift` | 取选中文字、截图、OCR、各翻译引擎 |
| `Core.swift` | 设置、语言、快捷键、翻译源、历史记录、剪贴板监听 |
| `TranslateUI.swift` | 翻译窗口 |
| `SettingsUI.swift` | 设置窗口 |
